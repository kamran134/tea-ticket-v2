## Этап 6б. Тема на публичных страницах — РЕШЕНО 04.09.2026

Проблема: `ThemeToggle` живёт внутри `Header`, а Header на публичных страницах скрыт,
поэтому покупатель не мог добраться до тёмной темы вообще.

Решение владельца — следовать системной теме:

- [x] `systemTheme()` читает `prefers-color-scheme`
- [x] `readExplicitTheme()` отделяет «выбрал светлую» от «не выбирал» — следовать ОС
      можно только во втором случае
- [x] `applyTheme()` больше не пишет в localStorage (иначе тема от ОС замерзала бы
      при первой же отрисовке); запись вынесена в `persistTheme()`
- [x] `ThemeProvider` слушает смену системной темы, пока явного выбора нет
- [x] Инлайн-бутстрап во всех четырёх html тоже смотрит media query — без вспышки светлого
- [x] Тесты переписаны под разделение apply/persist, добавлены регрессии на оба случая
