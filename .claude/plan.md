# План: Сетка = реальные зоны/места + зона без мест

## Концепция
«Сетка» (`GridMapEditor`) перестаёт быть черновиком-калькулятором поверх `Venue.gridLayout`
и становится редактором над настоящими `Zone`/`Seat`. Закрашенная ячейка — либо реальное
место (`Seat`, для `type: SEATED`), либо просто часть визуальной области зоны без мест
(`type: GENERAL`, вместимость — отдельное число). Сетка используется и на покупке билета
вместо «Схемы». «Схема» (`ZoneMapEditor`/`VenueMap`) скрывается из UI, код не удаляется.

# Часть 2: фикс синхронизации мест + убрать номер карты (заглушка оплаты)

## Баг
`PUT /:id/grid-layout` синхронизировал места для *всех* зон типа SEATED в мероприятии,
а не только для тех, что реально участвуют в сетке. Зона, созданная через старую
вкладку «Зоны» (генератор рядов/секций), никогда не красилась на сетке — при любом
сохранении сетки её места считались «удалёнными из сетки» и попадали под защиту от
удаления забронированного места → ошибка 409 на ровном месте.

# Часть 4: корзина, гости без имён, шаблоны сетки, реорганизация админки

## Решения (подтверждены пользователем)
- Мульти-зона = корзина: добавляешь места/количество из разных зон (в т.ч.
  смешивая «с местами» и «без мест»), один чекаут (имя/телефон) в конце.
  Один `groupId` на все билеты корзины независимо от зоны.
- Гости без имён: у корзины есть общее число билетов N (первый — сам
  покупатель). Либо вводишь имена остальных N-1, либо просто оставляешь
  как есть — тогда имена авто: «Гость 1», «Гость 2»... Отображение по
  месту нужды в формате «Имя + N».
- Шаблоны сетки: просто именованные шаблоны (без сущности «заведение»).
  Шаблон хранит форму сетки + описание зон (имя/цвет/тип/вместимость для
  GENERAL) — БЕЗ цены/номера карты, их admin проставляет при применении.
- «Зоны» скрываем, но столы используются → перенести управление столами
  и редактирование цены/названия зоны в «Схему» (бывшая «Сетка»).
- Валюта — жёстко манат везде, дропдаун убрать.
- Заодно: форма «Редактировать мероприятие» (имя/дата — валюту не показывать,
  она теперь всегда манат) на карточке в «Мероприятиях».

## Известные упрощения (сознательно, из-за объёма задачи)
- Корзина полностью работает для сетки (`VenueGridMap`) и столов. Для старой
  «Схемы» (`VenueMap`, зоны с `layoutData`) — тоже пишет в общую корзину,
  но это уже депрекейтед-путь (создавать такие зоны больше негде в админке)
- «Имя + N» и сумма по фактическим ценам — только на странице билета
  покупателя (`TicketView`). В списке билетов админки — как было, построчно
- В списке участников группы показывается зона каждого, без номера
  места/стола (это отдельный API-вызов, не стал усложнять)
