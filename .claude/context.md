# Контекст: юридические страницы

Источник текстов: Word-файлы 01–09 (RU/EN/AZ). Содержание переносится дословно, включая плейсхолдеры `[ЗАПОЛНИТЬ]` / `[TO FILL IN]` / `[DOLDURULMALIDIR]`.

Юридические тексты **не** кладутся в `i18n/locales/*` — они слишком большие и не UI-строки. Хранятся как `.txt` рядом с кодом страниц; переключатель языка тот же `changeLanguage()`.

URL без языкового префикса (как остальной публичный сайт):

- `/privacy-policy`
- `/terms`
- `/refund-policy`

Header/Footer возвращаются через общий `PublicLayout`, без копирования разметки. Контактные поля в `lib/site.ts` по-прежнему пустые — пустые ссылки в Footer не рендерим.
