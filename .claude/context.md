# Контекст: владелец мероприятия

У `Venue` есть `createdById` (опционально, `onDelete: SetNull`). При создании
записывается текущий админ. Super Admin видит и меняет все события; остальные —
только свои. Публичная афиша и `/e/:slug` без фильтра по автору.

Проверка на backend: `services/venue-access.ts`. Список в админке берётся из
`GET /api/venues?all=true` и сам сужается. Сканер: Super Admin — любой билет,
остальные — только билеты своих мероприятий.

События без автора (удалённый пользователь или до миграции) видит только Super Admin.
Миграция `20260907180000_venue_created_by` вешает существующие строки на первого Super Admin.
